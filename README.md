# Pictura Creations | Townsville, Queensland 📸🎥

**Pictura Creations** is Townsville, Queensland's premier visual storytelling studio specializing in cinematic photography, high-definition 4K videography, aerial drone productions, and live streaming.

---

## 🌟 Key Features
- **Modern Dark Glass & Liquid Metal UI/UX**
- **Townsville QLD Local SEO Optimization**
- **Interactive Bespoke Package Customizer & Pricing Calculator**
- **Classic Digital Invoice & Receipt Generator**
- **Google Reviews Integration (Elfsight Auto-Sync & Google Maps)**
- **Google Sheets Webhook Lead Logging Integration**

---

## 🚀 Quick Start
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Production build & deploy to GitHub Pages
npm run deploy
```
